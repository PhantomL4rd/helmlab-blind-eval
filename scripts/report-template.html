Which FF14 dye actually looks closest?

Compared here against the current algorithmic mapping and against CIEDE2000, OKLab, and Helmlab ranks, computed only after the human picks were already recorded.

Methodology

For each target, the evaluator first shortlisted plausible dyes from the entire candidate pool (hue-sorted, no algorithm involved) — Phase 1. Only within that self-built shortlist did side-by-side comparison happen, in randomized order — Phase 2. No recommendation, rank, or color-difference score from any algorithm was shown at any point during evaluation.
